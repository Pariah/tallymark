# Tallymark

Lockouts, quests, currencies, items, reputations and cooldowns for every character, on one board. For WoW Forever.

## Install

Copy the `Tallymark` folder into `World of Warcraft/_forever_/Interface/AddOns/`. Type `/tally` in game.
